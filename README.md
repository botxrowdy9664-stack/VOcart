# Gizmos Store - Animated E-commerce Site

A premium, high-fidelity electronics store UI built with React, Tailwind CSS v4, GSAP, Framer Motion, and Lenis.

## 🚀 How to Run the Project

Follow these steps to get the project running on your local machine:

### 1. Open your Terminal
Open a terminal (Command Prompt, PowerShell, or Git Bash) and navigate to the project directory:
`d:\tmp\PROJECTS\PROJECT_2`

### 2. Install Dependencies
If you haven't already, install the required packages using npm:
```bash
npm install
```

### 3. Start the Development Server
Run the following command to start the Vite development server:
```bash
npm run dev
```

### 4. View the Site
Once the server starts, you will see a URL like `http://localhost:5173/`. 
**Ctrl + Click** that link or copy-paste it into your browser to view the website.

---

## 🛠️ Tech Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP (ScrollTrigger, Timelines)
- **Micro-interactions**: Framer Motion
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
